==================================================
  나라장터 입찰정보 시스템 - 사용설명서
==================================================

나라장터(g2b.go.kr)의 발주계획/입찰공고/낙찰결과를
키워드로 자동 수집하고, 새 공고가 뜨면 알림을 주는 프로그램입니다.


■ 1. 실행 방법
--------------------------------------------------
1) 이 폴더 안의 "나라장터입찰정보.exe"를 더블클릭
   * 주의: exe만 다른 곳으로 빼내지 마세요.
     옆의 _internal 폴더와 한 세트라 폴더째 있어야 실행됩니다.

2) 처음 실행 시 파란 경고창("Windows의 PC 보호")이 뜨면
   [추가 정보] -> [실행] 을 누르세요.
   (서명 인증서가 없는 자체 제작 프로그램이라 뜨는 정상 경고입니다)

3) 인터넷이 연결되어 있어야 합니다.


■ 2. 처음 한 번만: API 인증키 설정
--------------------------------------------------
이 프로그램은 정부 공공데이터포털의 공식 API로 데이터를 받아옵니다.
무료이며, 본인 명의의 인증키가 필요합니다.

1) www.data.go.kr 회원가입 후 로그인
2) 검색창에 "나라장터" 검색 -> 아래 3개 서비스 각각 [활용신청] 클릭
   - 조달청_나라장터 입찰공고정보서비스
   - 조달청_나라장터 낙찰정보서비스
   - 조달청_나라장터 발주계획현황서비스
   (활용목적은 "앱 개발" 등 간단히 적으면 자동승인됩니다)
3) 마이페이지 -> 일반 인증키(Decoding) 복사
   * 꼭 "Decoding" 버전을 복사하세요! (Encoding 버전은 오류남)
   * 발급 직후에는 1~2시간 뒤부터 동작할 수 있습니다.
4) 프로그램 실행 -> [설정] 탭 -> 인증키 붙여넣기 -> [저장]


■ 3. 화면 안내 (탭 4개)
--------------------------------------------------
[공고 검색]  수집된 공고를 구분/분야/검색어/날짜/예산으로 조회
             마감일 옆 D-7, D-3 표시 = 입찰 마감까지 남은 날짜
             (D-3 이내는 빨간색 = 서두르세요!)
             [엑셀 내보내기]를 누르면 exports 폴더에 저장됩니다.

[낙찰 현황]  어떤 업체가 얼마에 수주했는지 확인
             업체별 수주 순위 / 월별 추이 / 수요기관별 발주 순위

[알림 내역]  지금까지 온 알림을 날짜/키워드로 다시 찾기

[설정]       인증키 / 검색 키워드 / 제외 키워드 / 검색 기간 /
             예약 검색 시각 관리
             * 키워드는 콤마(,)로 여러 개: 예) OCR, 챗봇, 검색엔진, AI
             * 제외 키워드: 제목에 이 단어가 있으면 수집 안 함
             * 추천 키워드 칩을 클릭하면 자동으로 추가됩니다


■ 4. 자동 감시와 알림
--------------------------------------------------
- 설정한 예약 시각(기본 09:00, 16:30)마다 자동으로 새 공고를 수집하고,
  새로 발견된 공고가 있으면 화면 오른쪽 아래에 Windows 알림이 뜹니다.
- 알림을 클릭하면 해당 공고의 나라장터 페이지가 열립니다.
- ★ 중요: 프로그램이 켜져 있어야 자동 수집/알림이 동작합니다.
  출근하면 켜두고 퇴근할 때 끄는 식으로 쓰세요.
- 지금 당장 수집하고 싶으면 상단의 [즉시 수집] 버튼을 누르세요.


■ 5. 자주 묻는 질문
--------------------------------------------------
Q. 알림이 안 와요.
A. (1) 프로그램이 켜져 있는지 (2) [설정]의 예약 시각이 맞는지
   (3) Windows 설정 > 알림이 꺼져있지 않은지 확인하세요.
   새 공고가 없으면 알림도 없습니다(중복 알림 안 함).

Q. 데이터/설정은 어디에 저장되나요?
A. 이 폴더 안 data 폴더입니다. (settings.json = 설정, g2b.db = 수집데이터)
   프로그램을 새 버전으로 바꿀 때 data 폴더만 지키면
   키워드와 수집데이터가 그대로 유지됩니다.

Q. 검색기간을 길게 하면?
A. [설정]에서 최대 365일까지 가능합니다. 길수록 최초 수집이 오래 걸립니다.

Q. 인증키를 남과 공유해도 되나요?
A. 안 됩니다. 본인 명의 발급이며 호출량도 본인 것에서 차감됩니다.
   PC마다 각자 키를 발급받아 쓰세요. (무료, 5분 소요)


■ 6. 데이터 출처
